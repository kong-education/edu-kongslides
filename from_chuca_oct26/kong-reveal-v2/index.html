What breaks first.

Spoiler: it isn't the model.

Three things break before the model does.

  • Auth. Every server invents its own.
  • Visibility. Nobody can say which agent called what.
  • Cost. Tokens add up quietly, then loudly.

Demo vs. production.

Demo

  • One server, one developer
  • Credentials in a config file
  • Nobody is watching the logs

Production

  • Dozens of servers, many teams
  • Identity and access, enforced centrally
  • Every call traced and costed
